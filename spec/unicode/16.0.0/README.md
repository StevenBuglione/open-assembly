# Unicode 16.0.0 data

The three gzip files preserve the original UTF-8 Unicode Character
Database text from the versioned upstream archive. The generator
checks the SHA-256 of each uncompressed source before deriving the
assembly range tables. The Unicode Data Files are copyright Unicode,
Inc. and distributed under the accompanying Unicode License V3.
[Unicode 16.0.0 UCD](https://www.unicode.org/Public/zipped/16.0.0/UCD.zip).
